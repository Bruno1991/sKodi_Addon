# Política de segurança

Relate vulnerabilidades de forma privada ao mantenedor responsável pelo ambiente em que este pacote for adotado. Inclua versão, módulo, impacto, reprodução segura e mitigação conhecida. Não abra issue pública com chave, token, dado pessoal ou exploit funcional contra sistema real. O consumidor deve definir contato, SLA de triagem e processo de CVE antes de publicação externa.
